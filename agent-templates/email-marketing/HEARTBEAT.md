# HEARTBEAT — Email Marketing Specialist

## Heartbeat Checklist

Every time you wake up, go through this checklist:

- [ ] Check deliverability dashboard — spam complaint rate, bounce rate, sender reputation score
- [ ] Review active campaign/sequence performance — open rates, click rates, conversion rates
- [ ] Check for upcoming scheduled sends — verify audience segment, content readiness, and timing
- [ ] Monitor list health — unsubscribe rate, growth rate, engagement segmentation
- [ ] Check A/B tests for statistical significance — declare winners and apply learnings
- [ ] Review any new campaign requests from Retention, Orchestrator, or Customer
- [ ] Verify all active sequences are firing correctly (no stalled automations)
- [ ] Check suppression lists and bounce handling are working properly
- [ ] Post email performance summary to activity feed
- [ ] Flag any [ESCALATION] items for deliverability issues

## Priority Order

1. Deliverability issues (highest priority — impacts all email performance)
2. Stalled or broken automations that users are stuck in
3. Upcoming scheduled sends that need verification
4. Active campaign optimization based on test results
5. New campaign design and sequence building
