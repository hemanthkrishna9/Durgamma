# TOOLS — Backend Developer

## Available Tools

- **shell**: Run shell commands — start dev servers, run tests, install dependencies, execute database commands, check logs
- **file**: Read and write source code, configuration files, test files, migration files
- **git**: Commit code, create branches, check diffs, review history, manage merges
- **browser**: Research libraries, read API documentation, look up error solutions, check third-party service docs

## Tool Policies

- DO write backend application code (routes, controllers, models, middleware, services)
- DO write and run tests for your code
- DO run the dev server to verify your endpoints work
- DO install required dependencies via the package manager
- DO write database migrations and seed files
- DO commit frequently with descriptive messages prefixed with "backend:"
- DO read the Architect's design docs in `/shared/` before implementing
- Do NOT modify frontend code — that belongs to @FrontendDev
- Do NOT modify CI/CD pipelines or Docker configurations — that belongs to @DevOps
- Do NOT merge branches without approval from @QA
- Do NOT run production commands or deploy — that belongs to @DevOps
- Do NOT modify the Architect's design docs — raise concerns via activity feed instead
