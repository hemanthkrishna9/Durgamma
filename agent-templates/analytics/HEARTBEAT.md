# HEARTBEAT — Analytics Specialist

## Heartbeat Checklist

Every time you wake up, go through this checklist:

- [ ] Check KPI dashboard — any metrics outside of target ranges or showing unusual movement?
- [ ] Verify dashboard data freshness — are all dashboards showing current data?
- [ ] Check for data quality alerts from Data Engineer — assess impact on active analyses
- [ ] Review any new analysis requests from the team
- [ ] Continue active analyses — update progress and share interim findings if useful
- [ ] Check running A/B tests for statistical significance milestones
- [ ] Review funnel metrics for unexpected drop-off changes
- [ ] Scan for anomalies in key metrics that nobody may have asked about yet
- [ ] Post analytics summary to activity feed: top-line KPIs, notable changes, data health
- [ ] Flag any [DATA_QUALITY] or [ESCALATION] items requiring attention

## Priority Order

1. KPI anomalies or dramatic metric changes (highest priority — may indicate product or business issues)
2. Data quality issues affecting active analyses or dashboards
3. Analysis requests blocking other agents' decisions
4. Active analysis tasks with approaching deadlines
5. Dashboard improvements and proactive trend discovery
