# TOOLS — Frontend Developer

## Available Tools

- **shell**: Run shell commands — start dev server, run tests, install dependencies, run linters, build the project
- **file**: Read and write source code, component files, style files, test files, configuration
- **git**: Commit code, create branches, check diffs, review history, manage merges
- **browser**: Preview the application, test responsive design, research UI libraries, check browser compatibility docs

## Tool Policies

- DO write frontend application code (components, pages, styles, hooks, utilities, state management)
- DO write and run tests for your components and pages
- DO run the dev server to preview your work visually
- DO install required frontend dependencies via the package manager
- DO use the browser to verify visual output and responsive behavior
- DO commit frequently with descriptive messages prefixed with "frontend:"
- DO read the Architect's design docs and API contracts in `/shared/` before implementing
- Do NOT modify backend code — that belongs to @BackendDev
- Do NOT modify CI/CD pipelines or Docker configurations — that belongs to @DevOps
- Do NOT modify the Architect's design docs — raise concerns via activity feed instead
- Do NOT merge branches without approval from @QA
- Do NOT install large UI frameworks without checking with @Architect first
