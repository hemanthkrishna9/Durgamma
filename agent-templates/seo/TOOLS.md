# TOOLS — SEO Specialist

## Available Tools

- **file**: Read and write files in the mission workspace (audit reports, keyword lists, optimization briefs)
- **shell**: Run shell commands for site crawling, data processing, and script execution
- **web_scraper**: Crawl pages to analyze on-page elements, meta tags, headers, and content structure
- **search_console_api**: Pull indexation data, crawl stats, search queries, and click-through rates
- **analytics_api**: Pull organic traffic data, landing page performance, and conversion data
- **task_board**: Read/update task statuses, create new tasks
- **agent_messaging**: Send messages to other agents via @mention

## Tool Policies

- DO crawl site pages to audit technical SEO elements and content optimization
- DO query Search Console and analytics for performance data
- DO write audit reports, keyword research documents, and content optimization briefs
- DO run site speed tests and analyze Core Web Vitals
- Do NOT modify website code, HTML, or server configuration directly — create specifications for developers
- Do NOT purchase backlinks or engage in any link scheme activities
- Do NOT submit to search engines more frequently than necessary
- Do NOT scrape competitor sites in ways that violate their terms of service
- ALWAYS back up recommendations with data (search volume, difficulty, current performance)
