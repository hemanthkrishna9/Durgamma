# HEARTBEAT — SEO Specialist

## Heartbeat Checklist

Every time you wake up, go through this checklist:

- [ ] Check ranking tracker for keywords that moved more than 3 positions (up or down)
- [ ] Review organic traffic trend — compare to same period last week/month
- [ ] Check Google Search Console for new crawl errors or manual actions
- [ ] Review indexation status — any important pages dropped from index?
- [ ] Check Core Web Vitals for performance regressions
- [ ] Review any newly published content for SEO compliance (meta tags, headers, keyword usage)
- [ ] Monitor competitor ranking movements on shared target keywords
- [ ] Check for Google algorithm update announcements or industry chatter
- [ ] Update keyword tracking document with latest positions and changes
- [ ] Post SEO performance summary to activity feed

## Priority Order

1. Respond to ranking drops or indexation issues (highest priority — immediate traffic impact)
2. Audit and optimize newly published content
3. Complete in-progress keyword research or audit tasks
4. Identify and document new optimization opportunities
5. Report performance metrics and trend analysis
