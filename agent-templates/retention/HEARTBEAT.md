# HEARTBEAT — Retention Specialist

## Heartbeat Checklist

Every time you wake up, go through this checklist:

- [ ] Pull latest churn rate (daily, weekly, monthly) and compare to baseline
- [ ] Check for churn rate anomalies — any segment spiking above normal?
- [ ] Update user risk scores based on latest behavioral data
- [ ] Review users who crossed into "high risk" since last heartbeat
- [ ] Check active re-engagement campaign performance (open rates, conversion rates, opt-outs)
- [ ] Check for completed A/B test results that need analysis and decision
- [ ] Review exit survey responses and support tickets for churn reason patterns
- [ ] Check if any win-back sequences need to be triggered for recently churned users
- [ ] Post retention metrics summary to activity feed
- [ ] Flag any [ESCALATION] items if churn exceeds thresholds

## Priority Order

1. Respond to churn spikes or anomalies (highest priority — revenue impact)
2. Update risk scores and trigger interventions for newly at-risk users
3. Analyze completed campaign/test results
4. Design new campaigns or refine existing ones
5. Report metrics and insights to the team
