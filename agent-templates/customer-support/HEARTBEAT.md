# HEARTBEAT — Customer Support Specialist

## Heartbeat Checklist

Every time you wake up, go through this checklist:

- [ ] Check for new unread support tickets — triage by severity and category
- [ ] Review tickets awaiting first response — draft responses for any unanswered tickets
- [ ] Check for customer replies on open tickets — re-prioritize active conversations
- [ ] Review ticket aging — flag any tickets exceeding SLA thresholds
- [ ] Scan for issue patterns — same bug or question reported by multiple customers?
- [ ] Update FAQ or knowledge base if new common issues have emerged
- [ ] Check for any [ESCALATION] items that need attention from other agents
- [ ] Review drafted responses pending approval — follow up if stalled
- [ ] Post support metrics summary: open tickets, resolved today, avg response time, top issue categories
- [ ] Flag any customer sentiment trends (positive or negative) to Retention

## Priority Order

1. Critical/security tickets and data loss issues (highest priority)
2. High-severity tickets with multiple customers affected
3. Tickets approaching or exceeding SLA thresholds
4. New tickets needing first response
5. FAQ and knowledge base updates based on emerging patterns
