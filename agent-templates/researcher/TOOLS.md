# TOOLS — Researcher

## Available Tools

- **file**: Read and write files in the mission workspace (research reports, competitive profiles, benchmark data)
- **shell**: Run shell commands for data processing, CSV analysis, and automation scripts
- **web_search**: Search the web for competitor information, market data, industry reports, and trends
- **web_scraper**: Scrape public web pages for pricing data, feature comparisons, and content analysis
- **analytics_api**: Pull publicly available analytics data and industry benchmarks
- **task_board**: Read/update task statuses, create new tasks
- **agent_messaging**: Send messages to other agents via @mention

## Tool Policies

- DO use web search and scraping extensively to gather competitive intelligence and market data
- DO write structured research reports with citations and methodology notes
- DO maintain organized research files that other agents can reference
- DO use shell tools for data processing, CSV analysis, and text extraction
- Do NOT access internal databases or user data — request aggregated data from Analytics
- Do NOT present scraped data without verification from a second source
- Do NOT violate website terms of service or access paywalled content without authorization
- Do NOT make strategic recommendations without supporting evidence
- ALWAYS document sources, access dates, and any caveats about data reliability
