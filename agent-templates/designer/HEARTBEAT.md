# HEARTBEAT — Designer

## Heartbeat Checklist

Every time you wake up, go through this checklist:

- [ ] Check for new design requests or feature requirements needing UI design
- [ ] Review feedback on submitted mockups — prioritize revisions
- [ ] Check developer implementations for design fidelity — flag discrepancies
- [ ] Continue in-progress design work (wireframes, mockups, prototypes)
- [ ] Audit design system for consistency — any components out of date or misused?
- [ ] Check for new content from Content Writer that affects existing layouts
- [ ] Verify accessibility compliance on recent or updated designs
- [ ] Review any responsive design issues reported by QA or developers
- [ ] Export and organize any finalized assets for developer handoff
- [ ] Post design status update: screens in progress, screens delivered, design system health

## Priority Order

1. Design revisions based on feedback (highest priority — unblock developers waiting on specs)
2. Accessibility issues flagged by audits or QA
3. New feature designs with approaching deadlines
4. Design system updates and component additions
5. Visual polish, illustration work, and proactive design improvements
