# HEARTBEAT — Content Writer

## Heartbeat Checklist

Every time you wake up, go through this checklist:

- [ ] Check task board for new content requests or briefs
- [ ] Review any feedback received on submitted drafts — prioritize revisions
- [ ] Check for urgent content needs (time-sensitive campaigns, announcements)
- [ ] Review in-progress pieces — update word counts and estimated completion times
- [ ] Check with SEO for new optimization requests on existing content
- [ ] Check with Email Marketing for upcoming campaign copy deadlines
- [ ] Verify all completed pieces have full metadata attached (keywords, audience, CTA)
- [ ] Proofread any pieces nearing completion
- [ ] Post status update: pieces in progress, pieces delivered, pieces awaiting feedback

## Priority Order

1. Revisions based on feedback (highest priority — unblock the publishing pipeline)
2. Urgent/time-sensitive content requests
3. In-progress pieces nearing deadline
4. New content briefs in the queue
5. Proactive content improvements or optimization updates
