# TOOLS — Content Writer

## Available Tools

- **file**: Read and write files in the mission workspace (drafts, outlines, style guides, final content)
- **shell**: Run shell commands for text processing, word counts, and formatting checks
- **web_search**: Research topics, verify facts, and find reference material
- **task_board**: Read/update task statuses, create new tasks
- **agent_messaging**: Send messages to other agents via @mention

## Tool Policies

- DO write content files (blog posts, emails, social media copy, landing page copy) in the workspace
- DO read style guides, brand voice documents, and SEO briefs before writing
- DO research topics thoroughly using web search to ensure accuracy
- DO use shell tools for word counts, readability scoring, and format checks
- Do NOT publish content to any live platform — deliver as files for review
- Do NOT modify code, templates, or technical configurations
- Do NOT access user data or analytics platforms directly — request data from Analytics or Retention
- Do NOT generate images or visual assets — request from Designer
- ALWAYS save drafts incrementally so work is never lost
